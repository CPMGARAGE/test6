BUILD A SAVE FILE

Pick what you want unlocked and download a backup file the game can import.

In the browser game, choose Save data, then Import backup. The downloaded game reads a plain save.json instead (see Install for where it goes). Either way, importing replaces the save on that device. To keep your real progress, settings, loadouts and custom tanks, load your own backup or save.json below and edit that. Everything runs in this page; nothing is uploaded.
